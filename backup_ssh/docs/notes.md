- Possible key types are `dsa`, `ecdsa`, `ecdsa-sk`, `ed25519`, `ed25519-sk`, `rsa`
- The key size is ignored for `ecdsa-sk`, `ed25519`, `ed25519-sk`
- Possible key sizes for `rsa` are `1024`, `2048`, `3072`, `4096`
- Possible key sizes for `ecdsa` are `256`, `384`, `521`

See the [OpenSSH Manual](https://man.openbsd.org/ssh-keygen) for detailed information.
