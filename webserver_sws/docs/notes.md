`sws_home` contains the configuration file `sws.toml` and the content served by Static Web Server:

| Path | Mounted as | Description |
|---|---|---|
| `sws.toml` | `/etc/sws.toml` | Configuration file, generated by the role |
| `public/` | `/var/public` | Content of the default host |
| `vhosts/<host>/` | `/var/vhosts/<host>` | Content of the virtual host `<host>` |

The role creates the directories, the content has to be deployed separately.

### Virtual hosts

Every entry in `sws_vhosts` becomes a virtual host in `sws.toml` with the root `/var/vhosts/<host>`:

```yaml
sws_vhosts:
  - 'example.com'
  - 'example.org'
```

Requests with a `Host` header not listed in `sws_vhosts` are answered from `public/`.

### Restarts

A running container is restarted when `sws.toml` or the quadlet unit changed, the first start of the container does not trigger an additional restart.

### Tests

The molecule scenario `default` runs the role in two [tart](https://tart.run) VMs on a macOS controller, the base VM has to be Debian 13.
The base VM is cloned for every platform and the clones are deleted afterwards, the base VM itself is never changed.
The playbooks creating and destroying the VMs are shared by all tart scenarios and live in `.molecule/tart/` in the repository root.

| Platform | Test case |
|---|---|
| `molecule-sws-ipv4-only` | Container with IPv4 address only, no virtual hosts |
| `molecule-sws-ipv6` | Container with IPv4 and IPv6 address and the virtual host `example.org` |

`prepare` sets up podman and the network `podman-molecule` with the role `container_podman`, pulls the image and creates test pages in `public/` and `vhosts/`.
`verify` checks the quadlet unit, `sws.toml`, the service, the container addresses and requests the pages via the container addresses, for `example.org` with the matching `Host` header.
The VMs need access to `ghcr.io` for the image.

Requirements on the controller: `tart`, `sshpass` (`brew install hudochenkov/sshpass/sshpass`), `molecule` and the collection `containers.podman`.

| Environment variable | Default | Description |
|---|---|---|
| `MOLECULE_TART_IMAGE` | `ghcr.io/cirruslabs/debian:latest` | Base VM or image that is cloned |
| `MOLECULE_TART_USER` | `admin` | SSH user of the base VM |
| `MOLECULE_TART_PASSWORD` | `admin` | Password of the SSH user, used to install the SSH key and for `sudo` |

```shell
cd webserver_sws
MOLECULE_TART_IMAGE='debian' molecule test
```
